# IH731_2026B
Curso: Tendencias en diseño de servicios
## Competencia general
El estudiante crea una infraestructura basada en servicios web que pueda ser consumida por diversas aplicaciones para la implementación de una aplicación que obtenga datos a través de un servicio.
## Contenido del curso
### Unidad 1. Introducción a los servicios web
Objetivo: Identificar los componentes de un servicio web, para la implementación de una aplicación que obtenga datos a través de servicios.

1.1 Conceptos básicos
1.2 Comunicación con un API
1.3 Aplicación HTML
### Unidad 2. Implementación de servicios web
Objetivo: Producir un conjunto de servicios web básicos y programar la aplicación cliente que hace uso de los servicios.

2.1 Hola, mundo de servicios
2.2 Manipulación de datos a través de servicios
2.3 CRUD + Cliente
### Unidad 3. Infraestructura de servicios
Objetivo: Crear una infraestructura propia de servicios que puedan ser consumidos por aplicaciones web y móviles, a partir de técnicas y mecanismos recomendados.

3.1 Persistencia de datos
3.2 Tendencias en servicios
3.3 Diseño y planeación
### Producto Integrador. Aplicación web
Objetivo: Crear una aplicación web para una infraestructura de servicios.
