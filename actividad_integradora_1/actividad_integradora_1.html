Cliente de APIs públicas con búsqueda dinámica

Esta aplicación consulta tres APIs públicas con fetch(). Cada formulario permite buscar información sin recargar la página y los resultados se muestran en tablas HTML.

1. JSONPlaceholder

Busca usuarios por ID, nombre, usuario, correo o ciudad.

Escribe un dato y presiona Buscar.

2. PokéAPI

Busca un Pokémon por nombre o por ID utilizando el mecanismo de búsqueda de la API.

Escribe un nombre o ID y presiona Buscar.

3. Dog CEO API

Busca razas y subrazas de perros a partir del listado proporcionado por la API.

Escribe una raza y presiona Buscar.
