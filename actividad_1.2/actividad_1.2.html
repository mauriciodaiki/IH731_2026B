Cliente de APIs públicas con Fetch

Esta aplicación consulta tres servicios públicos desde el navegador usando fetch() y muestra las respuestas en formato JSON.

1. JSONPlaceholder

Obtiene los datos del usuario con identificador 1.

Presiona el botón para consultar.

2. PokéAPI

Obtiene los datos del Pokémon Pikachu.

Presiona el botón para consultar.

3. Dog CEO API

Obtiene la URL de una imagen aleatoria de un perro.

Presiona el botón para consultar.
